## Design decisions

The short root file routes to branches so a quick explanation does not load a
complete thesis workflow. Optional templates give long-running work a durable
place without producing empty records for every question. Existing course and
assignment notes remain the owners; neither a second calendar nor a new database
is introduced. Status distinguishes produced artifacts from demonstrated learning.

Unknowns are the user's preferred reference manager, course-specific disclosure
requirements, typical available study time, and supported Study Manager editing
interfaces. Discover or ask for each only when it changes the requested task.
